# 硬體驗證

三台 D435i 的實機流程尚待驗收。完成以下項目後，才能評估真實環境的融合與路徑品質。

1. 以序號指定 LEFT／CENTER／RIGHT，記錄安裝位置。
2. 取得各串流解析度對應的內參，量測完整旋轉和平移外參。
3. 錄製 RGB、原始深度、有效遮罩、時間戳及校正資料，建立可重播案例。
4. 量測相機時間差、USB 降級、斷線與重連行為。
5. 檢查地面、斜坡、低矮障礙、反光材質與深度空洞。
6. 比對已知尺寸標靶、融合誤差、有效深度比例與處理延遲。

## 現有限制

- 相機按序號排序分配位置；預設 yaw 不是校正結果，平移外參尚未納入。
- 平行擷取不代表硬體同步。
- 地面分類使用高度百分位啟發式，假設近似平地。
- SDK 補洞及時間濾波可能產生估計深度，尚未量化對障礙邊界的影響。
- 固定規劃起點可能落在近距離盲區，會保守回報無路徑。
- 目前不輸出馬達命令，也沒有過期觀測阻擋或閉迴路控制。

診斷工具：`python tools/camera_intrinsics.py`。
